## 1. 概述

- **目标**：按需求文档落地 Bookshelf 首版（路线 A：Cloudflare 全家桶）。
- **总工期估算**：M0–M5 ≈ **5–5.5 周**（单人 / AI 协作）。
- **依据**：`DOCS/产品需求总指导文件.md` §11；专项设计：`数据模型与迁移手册` / `API接口手册` / `产品设计总指导文件`。
- **已确认决策**：路线 A、状态 3 态、砍阅读统计、AI 查询用 baseurl+api key（NL→过滤→只读）、导入导出成对。
- **估时单位**：人时（h）/ 人日（d，1d≈6h）。

## 3. 详细任务拆解

### M0 · 脚手架 + 一键部署（0.5 周）

**M0.1 项目初始化与构建链**（≈4h）
- [ ] 初始化 npm/pnpm 工程，`package.json` 脚本：`dev`(wrangler dev)、`deploy`(setup)、`typecheck`、`migrate`。
- [ ] 安装依赖：hono、@hono/zod-validator、drizzle-orm、drizzle-kit、bcryptjs、zod；dev: wrangler、vite、tailwindcss、typescript。
- [ ] `tsconfig.json` 严格模式 + `src/types` 共享类型雏形。
- [ ] Vite + Tailwind 配置，输出到 `dist/`。
- **验收**：`npm run typecheck` 通过；`vite build` 产出 `dist/`。

**M0.2 wrangler.toml 与绑定**（≈2h）
- [ ] 编写 `wrangler.toml`：`main=src/index.ts`、`assets.directory=./dist`、`compatibility_date`。
- [ ] 声明 `[[d1_databases]]`(DB)、`[[r2_buckets]]`(COVERS)、`[[kv_namespaces]]`(KV)；占位 binding 名。
- [ ] `vars`：非密钥配置（如 `APP_NAME`）；secret：`SESSION_SECRET`（签名 Cookie）、`AI_BASE_URL`/`AI_API_KEY`、`INITIAL_ADMIN_PASSWORD`。
- [ ] 声明 `_routes.json`：`/api/*` 走 Worker，`/assets/*` 与 `/` 走 SPA 兜底，避免 `/api` 被吞。
- **验收**：`wrangler deploy --dry-run` 配置解析通过。

**M0.3 数据库迁移**（≈3h，依据 `数据模型与迁移手册` §4）
- [ ] 编写 `migrations/0000_init.sql`（users/books/categories/tags/book_tags/settings/ai_query_log；books 含 translator/publish_year/page_count/original_title/started_at/finished_at/deleted_at）。
- [ ] `src/lib/db.ts`：Drizzle + D1 连接，`src/env.ts` 绑定类型。
- [ ] 本地 `wrangler d1 execute` 建表验证。
- **验收**：本地 D1 六张表存在；`books.status` CHECK 约束生效。

**M0.4 登录与会话**（≈4h，依据 `API接口手册` §2）
- [ ] `src/lib/auth.ts`：bcrypt 哈希、`verifyPassword`。
- [ ] `src/lib/session.ts`：Hono 签名 Cookie 签发/校验（`SESSION_SECRET`）。
- [ ] `src/api/auth.ts`：`/login`、`/logout`、`/me`（含首登强改口令）。
- [ ] 路由守卫中间件：未登录 → 401/重定向。
- **验收**：`POST /api/auth/login` 成功返 user；错误口令返 401；`/me` 需登录。

**M0.5 失败封锁（KV）**（≈2h，依据需求文档 §5）
- [ ] `src/lib/brute-force.ts`：KV 版 `check/record/reset`，key=`login:${ip}`，阈值 5/15min/锁30min。
- [ ] 接入 `auth.ts` 登录流程（失败 record，成功 reset，封锁返 429）。
- **验收**：连续 5 次错误口令后第 6 次返 429 + 剩余分钟；KV 跨实例生效。

**M0.6 AI 配置读取**（≈1h）
- [ ] `src/lib/settings.ts` + `src/env.ts` 读 `AI_BASE_URL`/`AI_API_KEY`（secret/env）。
- **验收**：能读取 secret 值（本地 `.dev.vars` 或 env）。

**M0.7 一键部署脚本**（≈3h，依据需求文档 §9）
- [ ] `scripts/setup.ts`：wrangler login（或 CF_API_TOKEN）→ d1 create → r2 create → kv create → 写回 wrangler.toml → 迁移 → seed 初始 admin（INITIAL_ADMIN_PASSWORD）→ secret put（SESSION_SECRET/AI）→ deploy。
- [ ] `README.md`：写明前提（CF 账号、npx wrangler、AI key）与命令。
- **验收**：clean 环境跑 `npm run deploy` 完成 provision + 部署。

**M0.8 本地跑通验证**（≈2h）
- [ ] `src/index.ts` 挂载路由 + Assets 托管；`/api/health` 返回 ok。
- [ ] `wrangler dev` 起全栈，首页可访问、登录接口可跑。
- **交付物**：可部署工程 + wrangler.toml + 迁移 + setup + README。
- **退出标准**：`wrangler dev` 起得来；表已建；登录/登出/me 通；setup 脚本能 provision。

### M1 · 数据模型 + 核心 CRUD（1 周）

**M1.1 Repository 与校验**（≈4h，依据 `数据模型与迁移手册`/`API接口手册` §3–5）
- [ ] Drizzle schema（books/categories/tags/book_tags）与 repository 封装。
- [ ] zod 校验 schema：bookCreate/bookUpdate、categoryCreate、tagCreate。
- [ ] 统一错误响应（`error.code/message`）。
- **验收**：typecheck 通过；校验覆盖必填与枚举。

**M1.2 书籍 CRUD**（≈5h）
- [ ] `POST /api/books`（默认 status=unread）、`GET /api/books/:id`、`PATCH /api/books/:id`、`DELETE /api/books/:id`（软删置 deleted_at）、`GET /api/books/trash`、`POST /api/books/:id/restore`、`DELETE /api/books/trash/:id`（物理删）。
- [ ] 列表 `GET /api/books`：参数化过滤（status/category/tag/q/trash）+ 排序（updated_desc|updated_asc|title_asc|title_desc|rating_desc）+ 分页/全量；状态变更自动写 started_at/finished_at。
- [ ] 标签写入：建 book 时按名 upsert tags 并写 book_tags。
- **验收**：CRUD 全通；过滤正确；无 SQL 拼接。

**M1.3 分类 / 标签 CRUD**（≈3h）
- [ ] `GET/POST /api/categories`（含 count）、`PATCH/DELETE`（删分类置 NULL）。
- [ ] `GET/POST/DELETE /api/tags`（唯一约束、级联删关联）。
- **验收**：分类/标签增删查通；count 正确。

**M1.4 测试与联调**（≈3h）
- [ ] 对核心接口写最小冒烟测试（vitest + 本地 D1 / 内存）。
- [ ] 用 curl/前端桩验证往返。
- **交付物**：books/categories/tags 完整 CRUD + 测试。
- **退出标准**：CRUD 全通、校验通过、关键路径有测试。

### M2 · 双视图 + 筛选 + 响应式 + 登录门禁（1 周，依据 `产品设计总指导文件`）

**M2.1 前端骨架与布局**（≈4h）

- [ ] Tailwind 设计 token 接入（shelf 色板、暗色 class）。
- [ ] 路由/状态：authed、theme、currentView、filters。
- **验收**：布局渲染；暗色可切。

**M2.2 双视图与列表**（≈5h）
- [ ] BookTable（Notion 式）+ BookGrid + BookCard；视图切换。
- [ ] 列表调 `GET /api/books` 渲染、数量统计、空态、加载态。
- [ ] 状态快速切换（行内 PATCH）。
- **验收**：双视图切换、状态切换生效。

**M2.3 筛选与搜索**（≈4h）
- [ ] Sidebar：StatusFilter(3 态)/CategoryFilter/TagFilter；SearchBar 防抖。
- [ ] 筛选/搜索 → 更新 filters → 重新拉取。
- **验收**：按状态/分类/标签/关键词过滤正确。

**M2.4 详情抽屉 + 添加/编辑表单**（≈5h，补原型缺口）

- [ ] BookForm 添加/编辑共用：字段、豆瓣链接/ISBN 抓取预填（接 M3 接口，先留桩）、提交 POST/PATCH。
- [ ] 编辑按钮真正打开表单（原型缺口）。
- **验收**：详情可看；新增/编辑可提交并回显。

**M2.6 回收站与设置面板**（≈3h，依据 `产品设计总指导文件` §4 + `API接口手册` §3.6–3.8）

- [ ] 设置面板：AI 配置说明、**修改口令**入口（首登强改 + 日常改）。
- **验收**：回收站恢复/彻底删生效；改口令可用。

**M2.5 登录门禁与响应式**（≈4h）
- [ ] LoginPage（新建，首登强改口令）、登出、会话守卫、失败封锁提示（倒计时）。
- [ ] 未登录重定向登录；移动端 Sidebar 抽屉 + FAB + 表单全宽。
- **验收**：未登录不可读写；移动端可用。

**交付物**：可用书架前端 + 门禁。
**退出标准**：双视图/筛选/搜索可用、移动端可用、登录门禁生效。

### M3 · 豆瓣抓取 + 封面（1 周，依据需求文档 §6 / `API接口手册` §6）

**M3.1 解析与抓取工具**（≈5h）
- [ ] 迁移 Redesk `book-metadata.ts` 正则解析（豆瓣/NeoDB/通用 OG）→ 适配 Workers。
- [ ] `fetch-utils.ts`：随机 UA + Referer + 按域限速(KV) + 10s 超时 + 3 次退避重试 + 429。
- **验收**：单测覆盖各源解析。

**M3.2 兜底链与探针**（≈3h）
- [ ] `POST /api/books/metadata/fetch`：豆瓣→NeoDB→Open Library(ISBN)→Google Books→手动。
- [ ] M3 探针：Worker 实测抓豆瓣，记录可达性，文档记结论；不可达主用 API 源。
- **验收**：各源可取元数据；失败返 400 + 提示。

**M3.3 封面代理与缺图兜底**（≈3h）
- [ ] `covers.ts`：Image Resizing / R2 代理下发；缺图渐变兜底（原型 cover-pattern）。
- [ ] 录入流程接抓取：贴链接/ISBN → 预填（打通 M2.4 桩）。
- **验收**：封面显示；缺图有渐变；预填可用。

**交付物**：链接/ISBN 自动元数据 + 封面。
**退出标准**：主要场景成功；失败可手填；封面正常。

### M4 · AI 查询（1 周，依据需求文档 §7 / `API接口手册` §7）

**M4.1 LLM 调用封装**（≈4h）
- [ ] `src/lib/ai.ts`：OpenAI 兼容 fetch（baseurl+key），超时/重试。
- [ ] system prompt：NL → JSON 过滤条件（status/tags/authorContains/titleContains）。
- **验收**：给定问句稳定返回结构化过滤 JSON。

**M4.2 查询端点与只读保证**（≈4h）
- [ ] `POST /api/query`：登录保护 → 调 LLM → 过滤 → 参数化只读查询 → 返回 items+filter。
- [ ] `ai_query_log` 轻量记录（每次查询写 query_text/filter_json/row_count/ip/ok）。
- [ ] system prompt 明确过滤 JSON 结构（status/category_id/tags/authorContains/titleContains/finishedAfter/finishedBefore），仅只读。
- **验收**：NL 查到书；仅只读；无 LLM 生成 SQL。

**M4.3 前端查询体验**（≈3h）
- [ ] 主页查询框 + 结果以 BookList 呈现（复用）。
- [ ] 错误/空结果提示。
- **交付物**：AI 查询可用。
- **退出标准**：NL 能查到书；仅只读；前端可用。

### M5 · 导出 + 导入 + 暗色 + 打磨（0.5 周）

**M5.1 导出**（≈2h，依据 `API接口手册` §8）

- **验收**：导出文件可被导入还原。

**M5.2 导入**（≈3h，依据需求文档 §8 / `API接口手册` §9）

- [ ] 前端 ImportExportPanel：导出/导入入口 + 结果展示（imported/updated/skipped/errors）。
- **验收**：导入 upsert 正确；错误行进 errors 不中断。

**M5.3 暗色与打磨**（≈3h）
- [ ] 暗色模式接原型 class + 持久化（若 M2 未完善）。
- [ ] 响应式/空态/错误提示打磨；一键部署脚本终验（clean 环境）。
- **交付物**：完整首版（含导入导出）。
- **退出标准**：导出/导入可用、暗色可用、部署脚本通过。

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| 豆瓣封数据中心 IP | 兜底链 + M3 探针 |
| 封面防盗链 / 大图 | Image Resizing / R2 代理 |
| 登录爆破 | brute-force KV 封锁 |
| Worker 内存限速不持久 | 改 KV |
| LLM 误操作数据 | NL → 过滤 → 只读 |
| 导入脏数据 / 重复 | ISBN/书名+作者 upsert + 错误统计 |
