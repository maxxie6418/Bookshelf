## 修改摘要

需求（经用户确认的设计）：为外部 AI Agent 提供 REST 接口与 Key，支持查询/编辑/添加，并限制删除与修改频率。用户确认的参数：

- 接口形态：REST API + Bearer Key
- 频率限制：写操作 10 次 / 10 分钟；删除单独加严 10 次 / 1 小时
- Key 管理：多 Key + 可轮换，活跃上限 3 个
- 附加约束：禁止 AI 操作回收站

### 变更

**新增服务端库**

- `src/lib/agent-key.ts`：Agent Key 生成（`bsk_` 前缀 + 随机 base58）、SHA-256 哈希（KV 只存哈希，明文仅创建时返回一次）、KV 存储（`agent:key:<hash>` 存元数据、`agent:keys` 存活跃哈希列表）、`verifyAgentKey` / `listAgentKeys` / `createAgentKey`（上限 3，超限抛错）/ `revokeAgentKey`（撤销并清理限频计数）。
- `src/lib/agent-ratelimit.ts`：KV 窗口计数器。写限频 `WRITE_LIMIT=10` / `WRITE_WINDOW_MS=10min`；删除加严 `DELETE_LIMIT=10` / `DELETE_WINDOW_MS=1h`。`checkWriteLimit` / `checkDeleteLimit` 超限返回 `{ allowed:false, retryAfter }`。
- `src/lib/agent-auth.ts`：`requireAgentKey` 中间件，校验 `Authorization: Bearer <key>`，成功把 key 哈希挂 `c.get('agentHash')`，失败返 401 `INVALID_AGENT_KEY`。

**新增 API**

- `src/api/agent.ts`（挂载 `/api/agent`，Bearer 鉴权）：
  - `GET /books`：查询/搜索/状态/分类/分页（不限频）
  - `GET /books/:id`：详情（不限频）
  - `GET /categories`、`GET /tags`：只读列表（不限频）
  - `POST /books`：新增（写限频）
  - `PATCH /books/:id`：编辑（写限频）
  - `DELETE /books/:id`：仅软删 → 回收站（写限频 + 删除加严）
  - **不暴露**任何 `/trash`、恢复、彻底删除、清空回收站端点 → 从结构上禁止 AI 操作回收站
- `src/api/agent-keys.ts`（挂载 `/api/agent-keys`，登录管理员 session 鉴权）：
  - `GET /`：列出活跃 Key 元数据（无明文）
  - `POST /`：新建，返回明文一次；超 3 个返 409 `KEY_LIMIT_REACHED`
  - `DELETE /:hash`：撤销 Key，立即失效

**修改**

- `src/index.ts`：注册 `agentRoutes`（`/api/agent`）与 `agentKeysRoutes`（`/api/agent-keys`）
- `src/web/api.ts`：新增 `listAgentKeys` / `createAgentKey` / `revokeAgentKey`
- `src/web/components/settings-panel.ts`：新增「AI Agent Keys」管理区（列表 + 撤销 + 生成新 Key + 明文一次性展示与复制），并附限频/禁回收站说明文案
