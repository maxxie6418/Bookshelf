# 表格副标题撑列修复与上传封面入口提亮

- **日期**：2026-09-19
- **应用版本**：1.3.0（修订）
- **修改模型**：GLM-5.3-Flash

## 修改范围

1. **表格书名列长副标题撑列 bug**（用户实测反馈）：表格为自动列宽布局，`w-[80%]` 相对已撑大的单元格解析、无法约束长文本，长副标题把书名列撑开推挤后续所有列。修复：书名/副标题改为 `max-w-[240px]`、作者 `max-w-[150px]` 的像素级硬上限 + `truncate` 截断（与行内编辑行、豆瓣链接列的既有模式一致），超出显示省略号，hover 有完整提示、详情抽屉看全文。
2. **上传封面入口提亮**：编辑态「上传封面」按钮由中性灰改为强调色边框（`border-[var(--accent)]`），在长表单中更醒目。入口位置不变：详情抽屉 → 编辑 → 「封面 URL」下方（新增书籍无 id，不提供上传）。

## 涉及文件

- `src/web/components/book-list.ts`（renderBookRow 列宽上限）
- `src/web/components/book-edit-form.ts`（上传按钮样式）

## 验证情况

- `npm run typecheck`、`npm run build` 通过；`max-w-[240px]`/`max-w-[150px]` 已编译进产物 CSS；「上传封面」在 JS bundle 中存在。

## 剩余风险

- 表格其余单元格（标签列、状态列等）内容均为短文本或已有 max-w，无同类撑列问题；若未来新增列请沿用像素级 max-w + truncate 模式。
