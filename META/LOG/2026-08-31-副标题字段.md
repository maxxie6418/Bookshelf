## 修改摘要

### 字段切换（original_title → subtitle）

- 数据库：`migrations/0004_add_subtitle.sql` 幂等新增 `subtitle TEXT`（`ALTER TABLE ... ADD COLUMN`；重复执行会报 duplicate column，幂等保证由 bootstrap 检测承担）。
- 后端：`src/lib/books.ts`（BookInput/BookRow 字段、createBook INSERT 列与绑定、updateBook 部分更新）、`src/api/books.ts` 与 `src/api/agent.ts`（zod schema）、`src/web/api.ts` / `src/web/types.ts`。
- 导出/导入（`src/lib/csv.ts`、`src/api/export.ts`、`src/api/import.ts`）：CSV 表头「原书名」→「副标题」；导入读取 `副标题`，**兼容旧表头「原书名」**（`r['副标题'] ?? r['原书名']`）。
- 前端：`book-edit-form.ts`（共用表单组件，BookMetadata/els/collectPayload/fill）、`book-form.ts`（添加弹窗）、`detail-drawer.ts`（抽屉展示 + 编辑态）、`book-list.ts`（表格行书名下展示副标题）。
- `original_title` 数据库列保留为历史列（存量数据不回迁），代码层不再读写。

### 抓取解析增强（`src/lib/book-metadata.ts`）

豆瓣文件解析增加副标题：优先取信息区「副标题」字段；缺省时从书名冒号（`：`或`:`）拆分，前半为 `title`、后半为 `subtitle`（如「三体II：黑暗森林」→ title=三体II / subtitle=黑暗森林）。

### bootstrap 幂等补列（`src/lib/bootstrap.ts`）

新增 `ensureBookSubtitleColumn`：`PRAGMA table_info(books)` 缺列时 `ALTER TABLE books ADD COLUMN subtitle TEXT`，已存在跳过；`ensureAdmin` 在 `ensureBookShelvedFavoriteRebuild` 之前调用，兼容全新库与存量库；`ensureBookShelvedFavoriteRebuild` 的建表/拷贝 SQL 同步加入 subtitle 列。

### 文档同步

- `DOCS/数据模型与迁移手册.md` v1.3：字段表新增 subtitle、标注 original_title 为历史列；迁移策略新增 0004 说明。
- `DOCS/API接口手册.md` v1.4：Book 结构、创建/更新请求、两个 metadata/fetch 响应、导出说明中的字段全部切换为 subtitle；CSV 表头变更与兼容说明。
- `DOCS/产品需求总指导文件.md` / `DOCS/产品设计总指导文件.md`：字段列表与解析字段文本同步。

### 遗留修正（承接进行中的工作区改动）

工作区存在此前未提交的行内编辑/抓取刷新、界面打磨等改动；本次又修正了 4 处 subtitle 切换遗漏：

1. `src/lib/books.ts` createBook 的 VALUES 绑定残留 `input.original_title ?? null`（改后类型不存在，会导致 typecheck 失败）→ `input.subtitle ?? null`。
2. `book-edit-form.ts` / `book-form.ts` / `detail-drawer.ts` 表单仍用 `originalTitle`/「原作名」→ 全部切换 subtitle/「副标题」。
3. `src/lib/csv.ts` 表头未同步导致导出丢列（BOOK_COLUMNS 仍为「原书名」而 export 行键为「副标题」）→ 对齐为「副标题」。
4. 文档残留 original_title/原作名 4 处（数据模型/API/需求/设计）。

## 未验证内容与剩余风险

- **生产部署**：远程 D1 需执行 `wrangler d1 execute bookshelf --remote --file=./migrations/0004_add_subtitle.sql`；若直接部署新代码，bootstrap `ensureBookSubtitleColumn` 会在首次请求时幂等补列。建议先迁移再部署代码。
- `original_title` 存量数据未回迁到 subtitle（属有意保留）；若未来需要可写一次性迁移脚本。
- 豆瓣书名冒号拆分仅作缺省兜底：书名本身含冒号（非副标题语义）时拆分可能不完全准确，豆瓣信息区「副标题」字段优先，手动录入完全不受影响。
- 工作区仍包含同日上午未提交的行内编辑/界面打磨改动，与本次 subtitle 改动混在一起；提交时建议按功能拆分 commit。
