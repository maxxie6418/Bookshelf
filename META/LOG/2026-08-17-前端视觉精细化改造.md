# 前端视觉精细化改造日志

- 日期：2026-08-17
- 修改范围：前端 Web 界面视觉系统、组件样式、图标、封面占位、动效、空态/加载态
- 涉及文件：
  - `src/web/style.css`
  - `src/web/index.html`
  - `tailwind.config.js`
  - `src/web/ui.ts`

  - `src/web/components/login.ts`

  - `src/web/components/settings-panel.ts`

## 修改摘要

1. 建立「私人图书馆 · 纸质感编辑风」统一视觉系统：
   - 在 `style.css` 中定义 `:root` 与 `.dark` CSS 变量，覆盖背景、表面、文字、边框、强调色（琥珀）、阴影、圆角、缓动曲线。
   - 引入霞鹜文楷（LXGW WenKai）、Noto Serif SC、JetBrains Mono 字体。
   - 添加 `.paper-texture`、`.shadow-paper`、`.shadow-float`、`.transition-theme` 等工具类。

2. 替换全站 emoji 图标为统一 SVG：
   - 在 `ui.ts` 中新增 `iconSun`/`iconMoon`/`iconSettings`/`iconLogout`/`iconTrash`/`iconSearch`/`iconPlus`/`iconEdit`/`iconClose`/`iconBook`/`iconBookOpen`/`iconGrid`/`iconList` 等辅助函数。
   - 所有组件中的 emoji/字符图标均已替换为 SVG。

3. 重新设计书籍封面占位图：
   - 移除彩虹渐变 `cover-pattern-*` 类。
   - 新增基于书名哈希的低饱和暖调封面生成器 `renderCoverPlaceholder`，支持 grid/table 两种尺寸。

4. 重构顶栏与侧边栏：
   - 顶栏搜索框居中放大，操作按钮图标化，"添加书籍"改为描边强调色风格。
   - 侧边栏改为索引目录风格，当前项使用左侧强调线。
   - 统计卡片使用新视觉变量与等宽数字字体。

5. 打磨网格/表格视图与组件细节：
   - 网格卡片使用柔和阴影与 -0.5px hover 幅度，底部加入书架分隔感。
   - 表格视图减少边框噪音，增加行内边距与柔和 hover 背景。
   - 状态徽标、分类标签、评分星星、按钮样式统一迁移到 CSS 变量。
   - `detail-drawer.ts`、`book-form.ts`、`login.ts`、`trash-panel.ts`、`settings-panel.ts` 统一使用新设计系统。

6. 优化动效与过渡：
   - 列表入场动画缩短至 0.25s 并保留错落延迟。
   - 抽屉/弹窗使用 `cubic-bezier(0.16, 1, 0.3, 1)` 缓动。
   - 主题切换颜色/阴影平滑过渡。

7. 改进空态与加载态：
   - 加载时展示骨架屏（grid/table 各一套）。
   - 空态展示插画图标、文案与添加/清除筛选操作。
