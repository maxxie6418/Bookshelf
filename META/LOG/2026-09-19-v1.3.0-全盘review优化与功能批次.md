## 剩余风险

- 迁移双轨制（bootstrap 内置最终态 schema vs migrations 顺序执行）未统一（优化 3 未选中）：先请求后手动迁移的库仍可能卡在 0001，维持 README 既有说明。
- 登录暴破防护与 Agent 限频仍为 KV 非原子计数（优化 5 未选中），高并发下可超发/500，文档属性为「尽力而为」。
- SESSION_SECRET 缺省回退派生密钥、改密不验旧口令（优化 1/2 未选中）风险保持现状。
- CSV 公式防护会给以 `= + - @` 开头的纯文本单元格加 `'` 前缀，重新导入时该前缀会保留在文本中（标准做法，极端场景可手删）。
- 上传封面取消保存会留下孤儿 R2 文件，依赖既有「存储检查与清理」回收。
- Google Books 兜底在 Cloudflare 出口 IP 下大概率 429，仅作末位补充；NeoDB 若调整匿名策略会影响兜底链首位（失败自动降级到后续源）。
- `original_title` 存量数据未回迁 subtitle 的既定事实保持不变。
