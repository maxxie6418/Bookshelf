## 修改摘要

背景：用户远程登录 admin123 持续返回 500，但控制台无任何日志可查，无法定位具体错误。

修改：

- `wrangler.jsonc`：新增 `observability` 配置（`enabled: true`，logs 持久化 + invocation logs，traces 保持关闭省钱）
- `src/index.ts`：
  - 新增 `app.onError` 全局错误处理：将 `console.error('[error]', stack/message)` 写入运行日志，并统一返回 500 JSON
  - 将 `ensureAdmin` 从外层 `fetch` 移入 `app.use('/api/*')` 中间件，确保其异常也能进入 onError 记录错误栈

## 验证情况

- `npm run typecheck`：通过
- 本地 `wrangler dev`：observability 配置被正常接受，绑定无异常
- `GET /api/health` → 200；`POST /api/auth/login` 口令 admin123 → 200（`must_change_password:true`），onError 不影响正常流程

## 未验证内容与剩余风险

- observability 日志需在远程部署后于 Cloudflare 控制台（Workers → bookshelf → Logs）查看生效情况，本地无法验证远端日志 UI
