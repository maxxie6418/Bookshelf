## 修改摘要

需求（4 项）：① 左侧栏底部三按钮需贴最底部；② Agent 设置单独加按钮，与设置/主题/退出同排；③ 网格视图书籍卡片缩小约 50%；④ 书籍属性新增可编辑的「记录」文字属性，限制 2000 字以内。

### ① 侧栏底部按钮贴底

根因：`renderSidebar` 外层容器同时有 `flex-1 flex flex-col` 和 `space-y-6`，而底部操作区用 `mt-auto` 贴底。Tailwind 的 `space-y-6` 使用 `> :not([hidden]) ~ :not([hidden]) { margin-top: 1.5rem }` 选择器，其特异性高于单类 `mt-auto`，因而覆盖了 `mt-auto`，导致底部三按钮无法贴到最底。

修复（`src/web/components/app-shell.ts`）：把外层容器拆为 `flex-1 flex flex-col`，将统计卡/筛选区块包进 `flex-1 space-y-6` 子容器，底部操作区作为外层容器的平级子元素且单独使用 `mt-auto`，不再受 `space-y-6` 影响，三按钮贴到侧栏底部。

### ② 侧栏新增 Agent 设置按钮

- `src/web/ui.ts`：新增 `iconKey`（钥匙图标）。
- `src/web/components/settings-panel.ts`：抽取 `openAgentSettings()`，单独弹出「AI Agent 接入」模态，复用 `renderAgentKeysSection`（列出/新建/撤销 Key）。
- `src/web/components/app-shell.ts`：底部操作区在「主题」与「设置」之间新增一个钥匙按钮（title「Agent 设置」），与主题/设置/退出同排（`justify-around`）。

### ③ 网格卡片缩小约 50%

`src/web/components/book-list.ts` 两处网格（骨架屏与真实卡片）列数翻倍、间距减小：

- 网格列：`grid-cols-2 sm:grid-cols-3 md:grid-cols-4 xl:grid-cols-5 2xl:grid-cols-6` → `grid-cols-3 sm:grid-cols-4 md:grid-cols-6 xl:grid-cols-8 2xl:grid-cols-10`
- 间距：`gap-4 sm:gap-5 lg:gap-6` → `gap-3 sm:gap-4 lg:gap-5`
- 卡片文字相应微调：书名 `text-sm`→`text-[13px]`、作者 `text-xs`→`text-[11px]`，信息区 padding 收紧，适配更小卡片。

### ④ 书籍新增「记录」字段（≤2000 字）

**数据模型**：新增 `books.notes TEXT` 列。

- `migrations/0001_add_notes.sql`：`ALTER TABLE books ADD COLUMN notes TEXT;`（供 migrations_dir 记录）
- `src/lib/schema.ts`：新库建表定义中补充 `notes TEXT`（此后 `description`）
- `src/lib/bootstrap.ts`：新增 `ensureBookNotesColumn()`（幂等，`PRAGMA table_info` 检测缺失才 `ALTER`），并在 `ensureAdmin` 每次启动调用，适配已存在的本地/线上库自动补列

**服务端**：

- `src/lib/books.ts`：`BookInput`/`BookRow` 增加 `notes`；`createBook` INSERT 增加 `notes` 列与绑定；`updateBook` 支持 `notes` 字段
- `src/api/books.ts`、`src/api/agent.ts`：`bookSchema` 增加 `notes`，并限制 `z.string().max(2000, '记录最多 2000 字')`

**前端**：

- `src/web/types.ts`：Book 增加 `notes?`
- `src/web/components/book-edit-form.ts`：新增 `notes` textarea（`maxlength=2000`），加入 `collectPayload`；`EditForm.els` 增加 `notes`
- `src/web/components/book-form.ts`：弹窗在「简介」下方增加「记录」输入
- `src/web/components/detail-drawer.ts`：展示态在标签下方增加「记录」区块（`whitespace-pre-wrap`）；内联编辑在「简介」下方增加「记录」输入

涉及文件：

- 新增：`migrations/0001_add_notes.sql`
