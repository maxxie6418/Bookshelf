2. **第一轮历史重写**（`git filter-branch --env-filter` + `--index-filter`）：

3. **第二轮历史重写**（`git filter-branch --env-filter` + `--index-filter` 全文本过滤）：

   - 对全部历史提交中的普通文本文件（跳过二进制扩展名）执行统一文本替换；

   - 替换正文中的个人邮箱、Cloudflare Account ID、D1/KV 资源 ID；

   - `git reflog expire --expire=now --all` + `git gc --prune=now --aggressive` 清理不可达旧对象；

5. **日志提交身份修正**：本次清理新增的 META/LOG 提交曾沿用本机 Git 全局身份（原个人邮箱），已对整条 `main`（77 个提交）执行一次仅身份重写，统一为 `Bookshelf <maxxie6418@users.noreply.github.com>`；随后再次清理 `refs/original`、reflog 与不可达对象。

## 未验证内容与剩余风险

- **远程仓库未同步**：本地历史已清理，但 GitHub 远程仓库仍为旧历史，需执行强制推送（`git push --force-with-lease origin main`）后才能生效；此操作会改写远程历史，需用户确认后执行。

- **远程残留不可控**：GitHub 网页缓存、PR/Issue、Actions 工件、Release 附件、以及任何 Fork 或第三方克隆中的旧内容不会因本地清理自动消失；如需彻底处理需在 GitHub 平台侧手动清理。

- **本地备份引用保留**：`refs/backup/pre-privacy-cleanup-20260901` 指向清理前旧 HEAD（含已删除的构建日志与真实资源 ID），该引用仅存于本机，严禁推送到远程；确认无需回滚后应删除该引用并再次 `git gc --prune=now` 彻底清除本地旧对象。

- **`wrangler.prod.toml`** **占位符**：脱敏后文件中 D1/KV 资源 ID 为 `REPLACE_WITH_*` 占位符，实际部署前需在本地未跟踪配置或部署平台补回真实 ID。

- **本地 reflog 与其他机器**：本机 reflog 已清空；若项目在其他机器上仍有克隆，需在那些机器上重复拉取新历史或重新克隆。
