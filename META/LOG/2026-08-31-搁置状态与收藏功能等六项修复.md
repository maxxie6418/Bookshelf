## 修改摘要

### ① 侧边栏固定一屏高度（`src/web/components/app-shell.ts`）

侧栏容器由随内容拉伸改为 `sticky top-16 self-start h-[calc(100vh-64px)]`，配合 `overflow-y-auto` 使侧栏固定一屏高度、内部（分类/标签/操作区）独立滚动，不再随书籍列表拉动。

### ② 总藏书上限 100（`src/web/refresh.ts`）

统计与列表请求此前走服务端默认 `limit=100`，藏书超过 100 本时统计失真。新增 `ALL_LIMIT = 1000`，统计请求改传 `limit: ALL_LIMIT`，与文档约定「书籍 ≤ 1000 本」一致。

### ③ 录入时间 + 搁置状态（schema/migration/bootstrap/后端/前端）

- 数据库：`books.status` CHECK 扩展为 `('unread','reading','finished','shelved')`；新增 `favorite INTEGER NOT NULL DEFAULT 0 CHECK (favorite IN (0,1))`。
- 迁移 `migrations/0003_add_shelved_favorite.sql`：SQLite 无法改 CHECK 约束，需重建表。**关键坑**：D1 在隐式事务中强制执行外键，`PRAGMA foreign_keys=OFF` / `defer_foreign_keys` 均无效，直接 `DROP TABLE books` 会触发 `ON DELETE CASCADE` 级联清空 `book_tags`（实测 bt 3→0）。故采用 **rename-dance**：建 `books_new`/`book_tags_new` → 拷贝数据 → 旧表 RENAME 为 `*_old` → 新表 RENAME 为正式名 → DROP `*_old`，本地 D1 重复执行验证幂等、数据完整（bt=3、books=3）。
- `src/lib/bootstrap.ts`：新增 `ensureBookShelvedFavoriteRebuild`，部署时幂等检测（`PRAGMA table_info(books)` 是否含 `favorite` + `sqlite_master` 中 CHECK 是否含 `shelved`），未迁移库自动执行与 0003 相同的重建，已迁移库跳过。
- 后端（`src/lib/books.ts`、`src/api/books.ts`、`src/api/agent.ts`）：`VALID_STATUS` 增加 `shelved`；创建/更新支持 `favorite` 与 `created_at`（缺省 `datetime('now')`）；列表支持 `?favorite=1` 过滤。
- 导出/导入（`src/lib/csv.ts`、`src/api/export.ts`、`src/api/import.ts`）：CSV 新增「收藏」「录入时间」列；状态归一支持 `搁置`；导入保留原录入时间。
- 前端展示：详情抽屉新增「录入时间」字段；状态映射（卡片/表格/详情/表单）增加「搁置」。

### ④ 收藏功能

- 顶部过滤区新增独立「收藏」星标按钮（`book-list.ts`），样式与状态按钮组区分（独立边框/主题色，激活时高亮），不混排。
- 网格卡片封面左上角、表格操作列、详情抽屉底部均可一键收藏/取消（PATCH `favorite` 后刷新）。
- 添加/编辑表单新增「加入收藏」开关。
- `src/web/ui.ts` 新增 `iconStar`。

### ⑤ 工具栏间距（`src/web/components/book-list.ts`）

排序下拉与视图切换之后、「添加书籍」之前插入竖向分隔线 `<div class="w-px h-6 mx-1 bg-[var(--border-subtle)] hidden sm:block">`。

### ⑥ 设置中的分类/标签管理（`src/web/components/settings-panel.ts`）

设置 →「数据管理」新增「分类/标签」按钮，打开「分类与标签管理」弹窗（复用 `renderTaxonomyManage`），支持分类/标签新建、改名、删除，与侧栏「管理」入口能力一致。

### 浏览器验证中发现并修复的问题

- 网格卡片收藏星标按钮被封面 hover 覆盖层（`absolute inset-0 bg-black/0 group-hover:bg-black/10`）遮挡点击，`elementFromPoint` 实测命中覆盖层导致点击无效。修复：星标按钮加 `z-10`（`src/web/components/book-list.ts`），修复后命中 SVG 星标并正确触发切换。

## 未验证内容与剩余风险

- **生产环境部署**：远程 D1 需执行 `wrangler d1 execute bookshelf --remote --file=./migrations/0003_add_shelved_favorite.sql`；若直接部署新代码，bootstrap 的 `ensureBookShelvedFavoriteRebuild` 也会在首次请求时幂等重建（已对本地 D1 验证同一逻辑）。建议先执行迁移再部署代码。
