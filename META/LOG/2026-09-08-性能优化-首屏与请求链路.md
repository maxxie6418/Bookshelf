# 2026-09-08 性能优化：首屏与请求链路

- **文档版本**：1.0
- **文档状态**：生效
- **目的和适用范围**：记录 v1.2.0 性能优化（列表瘦身、刷新拆分、搜索防抖与竞态保护、封面异步解码、字体减负）的修改范围与验证情况；适用于 Web 前端与 Worker API。
- **权威级别**：模块规则（Web 前端 / Worker API 性能相关）
- **最后更新日期**：2026-09-08

## 修改摘要

- **列表接口瘦身**：`src/lib/books.ts` 新增 `LIST_SELECT`（排除 `description`/`notes`/`reason`），`listBooks()` 使用之；`getBook()` 用 `DETAIL_SELECT` 保持全量。
- **刷新拆分**：`src/web/refresh.ts` 新增 `refreshBooks()`（仅请求列表），`refresh()` 保留列表 + 统计；两者用模块级请求序号做竞态保护，旧响应不覆盖新结果。
- **搜索防抖**：`src/web/components/app-shell.ts` 移动端搜索 `oninput` 补 300ms debounce；搜索/筛选/翻页改调 `refreshBooks()`，初始加载与数据变更走 `refresh()`。
- **封面异步解码**：`book-list.ts` / `book-inline-edit.ts` / `detail-drawer.ts` 封面 `<img>` 增加 `decoding="async"`。
- **字体减负**：`src/web/main.ts` 移除未使用字重 import（Noto Serif 400、JetBrains Mono 500/600）。
- **版本号**：`1.1.1 → 1.2.0`（package.json / package-lock.json / 顶栏文案 / README）。

## 验证结果

- `npm run typecheck`：通过（tsconfig + tsconfig.web 双工程）。
- `npm run build`：通过。字体文件数 615 → 401（−35%），字体合计字节 21.0 MB → 14.0 MB；CSS 431.61 kB → 287.48 kB（gzip 183.54 → 118.46）；最大 JS chunk 约 92.6 kB（基本持平）。

## 未验证 / 剩余风险

- **导出字段变化**：`listAllBooks()` 走 `LIST_SELECT`，导出数据不再含 `description`/`notes`/`reason`（按 spec 约定归为列表侧，本次接受）。
- **字重合成渲染**：拆除 Noto Serif 400 后，个别 `font-medium`（原由 400 合成）改由 600 就近合成，存在轻微视觉边缘差异；如需精确控件字重可后续补导。
- 未做浏览器端交互实测（项目规则不擅自调外部浏览器）。
