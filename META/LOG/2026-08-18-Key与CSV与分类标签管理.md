## 修改摘要

### ① Agent Key：明文窗口持久展示 + 上次使用时间

**问题**：生成 Key 后展示明文的小窗消失过快，用户来不及复制；Key 列表无法区分各 Key 上次的使用时间，不利于多 Key 登录安全管理。

**持久明文展示（`src/web/components/settings-panel.ts`）**：新增 `showKeyPlaintext(plain, label)`，生成 Key 后弹出持久锁定遮罩（无遮罩点按关闭、无 X），内含可复制的明文与「复制」按钮（成功后按钮文案变「已复制 ✓」，失败自动全选明文），必须手动点「我已保存，关闭」才关闭。

**上次使用时间（`src/lib/agent-key.ts` + 设置面板）**：

- `AgentKeyMeta` 新增 `last_used_at?`。
- `verifyAgentKey` 在鉴权通过后以节流方式（模块级 `Map` + 60 秒节流）写回 `KV` 的 `last_used_at`，避免每次请求都写 KV。
- `revokeAgentKey` 清理对应节流项。
- 设置面板 Key 项展示「上次使用：xx｜从未使用」，便于识别各 Key 活动情况。

### ② CSV 导入 / 导出

**需求**：导出分「模版导出」与「内容导出」；导入需二次确认（上传后先预览列表、按 书名/ISBN/豆瓣链接 判断与已有书籍重复，默认勾选无重复项，可取消/新增勾选，确认后才写入，长导入显示进度条）。

**公共 CSV 工具（`src/lib/csv.ts`，新增）**：`BOOK_COLUMNS` 全字段列（书名/作者/译者/出版社/出版年份/页数/原书名/ISBN/简介/记录/豆瓣链接/评分/状态/分类/标签）；`toCsv`（BOM + CRLF + 转义）；`parseCsvRows`（字符级解析，兼容 BOM/CRLF/引号/内嵌逗号换行）；`normalizeTitle`（去重用书名规范化）；`normalizeStatus`（中英状态归一）。

**导出后端（`src/api/export.ts`，新增）**：
- `GET /api/export/template`：仅表头。
- `GET /api/export/books`：`listAllBooks` 导出全部未删除藏书为全字段 CSV，`Content-Disposition: attachment`。
- `src/lib/books.ts` 新增 `listAllBooks`（全量分页拉取）、`mapExistingByKey`（按 规范化书名/ISBN/豆瓣链接 的索引 Map，供去重）。

**导入后端（`src/api/import.ts`，新增）**：
- `POST /api/import/books/preview`：解析 CSV、逐行规范化、按 书名/ISBN/豆瓣链接 检测与已有书籍重复，返回每行 `valid/duplicate/matched` 与 summary。
- `POST /api/import/books/batch`：接收前端选中的行（≤50/批），按分类名自动建分类（色板轮换），调用 `createBook` 创建。
- 路由在 `src/index.ts` 挂载：`/api/export/*`、`/api/import/*`。

**前端（`src/web/components/import-export.ts`，新增；`src/web/api.ts`、`src/web/ui.ts`、`src/web/components/book-list.ts`）**：
- `renderImportExportButtons()` 挂到书单列表顶栏（排序/视图/添加之间）：导出下拉（导出模版 / 导出内容）+ 导入按钮（隐藏 file input）。
- `openImportFlow(file)`：上传后调用 preview → 渲染勾选列表（新增/重复徽标、已存在书籍、作者·ISBN·豆瓣）→ 全选/全不选 → 「确认导入」按 20/批逐批写入并更新进度条（宽度/百分比/「已导入 x/y」），完成后关闭并刷新。
- `api.ts` 新增 `requestText` 与 `exportTemplate/exportBooks/importPreview/importBatch`；`ui.ts` 新增 `iconDownload/iconUpload/iconExternal`。
