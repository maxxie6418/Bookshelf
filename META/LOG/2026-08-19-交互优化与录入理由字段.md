## 修改摘要

按用户四点需求与三项补充细节实现，共改动 22 个源码文件 + 新增 1 个迁移。

### 需求 1 — 状态改为顶部按钮组
- `src/web/components/book-list.ts`：移除右侧工具栏的「状态」下拉 `<select>`；在顶栏标题「全部书籍」旁新增「全部 / 未读 / 在读 / 读完」分段按钮组，当前项以强调色高亮。

### 需求 2 — 侧栏分类 / 标签分区 + 分割线
- `src/web/components/app-shell.ts renderSidebar`：分类区占上半部、标签区延伸至底部快捷图标前，两区之间增加细分隔线；各区独立滚动与间距。

### 需求 3 — AI Key 可复制（加密存储 + reveal 按需取）
- `src/lib/agent-key.ts`：用 SESSION_SECRET 派生 SHA-256 密钥对明文做 AES-GCM 加密，仅存密文+IV+前4/后4位（不存明文）；新增 `revealAgentKey`。
- `src/lib/session.ts`：导出 `getSessionSecret` 供复用同一有效 secret。
- `src/api/agent-keys.ts`：创建时传入 secret；新增 `POST /api/agent-keys/:hash/reveal` 按需回显明文。
- `src/web/api.ts`：新增 `revealAgentKey` 客户端方法。
- `src/web/components/settings-panel.ts`：Key 列表显示「前4+星号+后4」掩码；新增「复制」按钮点击时调用 reveal 复制明文；老 Key（无密文）安全降级（无后4/不可复制）。

### 需求 4 — 分类 / 标签侧栏内联管理（不弹窗，避免 UI 推挤）
- `src/web/components/manage-taxonomy.ts`：由弹窗改为 `renderTaxonomyManage` 内联渲染进侧栏分区；已存在项带「改名 / 删除」，末尾默认「待命名」新增行（命名后回车/保存创建，为空忽略即撤回）；行高固定、就地置换避免推挤。
- `src/web/state.ts`：新增 `taxEdit` 编辑态字段。
- `src/web/components/app-shell.ts`：分类/标签头部「管理 / 完成」切换内联编辑态。

### 需求 5 — 网格卡片顶部圆角
- `src/web/components/book-list.ts renderGrid`：封面容器补 `rounded-t-xl overflow-hidden`，使卡片四角圆角一致。

### 需求 6 — 详情抽屉
- `src/web/components/detail-drawer.ts`：展示态「记录」标签改「笔记」，新增「录入理由」展示块；底部改为「移入回收站」贴左下角、右排「关闭 / 编辑」；编辑态同步「笔记 / 录入理由」字段。
- 「录入理由」字段（≤1000 字）全链路：`src/lib/schema.ts`（建表列）、`src/lib/bootstrap.ts`（幂等补列）、`migrations/0002_add_reason.sql`（新增）、`src/lib/books.ts`（BookInput/Row/Create/Update）、`src/api/books.ts` + `src/api/agent.ts`（zod 校验）、`src/lib/csv.ts` + `src/api/export.ts` + `src/api/import.ts`（CSV 导入导出列）、`src/web/types.ts`、`src/web/components/book-edit-form.ts`、`src/web/components/book-form.ts`、`src/web/components/detail-drawer.ts`。

### 需求 7 — 底部四按钮改组合方形按钮组
- `src/web/components/app-shell.ts`：主题 / Agent / 设置 / 退出 由独立图标按钮改为 2×2 组合方形按钮组，与上方快捷链接样式区分。

### v1.3 — 底部样式互换与精简
- `src/web/components/app-shell.ts`：书签页（GitHub / Cloudflare / 豆瓣）改为盒式小方块卡片样式；设置/退出四按钮改为平铺扁平样式，二者位置不变仅互换样式。
- `src/web/components/book-list.ts renderGrid`：移除网格卡片底部的渐变细线条（`after:*` 渐变类）。

### v1.4 — 抽屉加宽 / README 截图 / AI 预置提示词
- `src/web/components/detail-drawer.ts`：详情抽屉宽度由 `sm:480 / lg:520` 加大为 `sm:600 / lg:680`，侧滑占比更多、内容更舒展。
- `README.md`：新增「界面预览」小节，以 2×2 表格引用 `pic/` 下四张截图（书架页 / 书籍属性 / 书籍编辑 / AI 接入）。
- `src/web/components/settings-panel.ts`：AI Agent 接入面板新增 `copyablePrompt` 组件与两段预置内容（`PROMPT_SETUP` 系统提示词接入说明、`PROMPT_CAPS` 能力说明），各带「复制」按钮，可一键复制整段发给外部 AI。

### v1.5 — 精简 AI 提示词 / 更换全局字体
- `src/web/components/settings-panel.ts`：删除「能力说明」提示词（`PROMPT_CAPS`）及其展示块——与系统提示词内容冲突，仅保留「系统提示词（接入说明）」一段，供一键复制发给外部 AI。
- `src/web/style.css`、`tailwind.config.js`：全局正文/`sans` 字体由手写风格 `LXGW WenKai` 改为系统无衬线字体栈（`-apple-system / PingFang SC / Microsoft YaHei / Noto Sans SC` 等），标题区保留 `Noto Serif SC` 衬线，去除手写观感。

### v1.6 — 详情抽屉展示重构
- `src/web/components/detail-drawer.ts` `displayBody`：
  - 书籍本身属性（作者/译者/出版社/出版年/ISBN/页数/豆瓣链接）统一放入带边框的「书籍属性」容器块。
  - 简介、标签之后，与下方「我的记录」区之间增加分割线。
- `src/web/components/detail-drawer.ts` 新增 `editableMemoBlock`：笔记（≤2000 字）与录入理由（≤1000 字）支持头部小「编辑」按钮内联展开 textarea、字数统计与「保存/取消」，直连 `api.updateBook` 保存，无需进入全表单编辑；保存后刷新列表与侧栏。

## 未验证内容与剩余风险

- 变更 SESSION_SECRET 后，历史 AI Key 无法 reveal 回显（bearer 鉴权不受影响），属预期的安全行为。
- 「录入理由」为新增 DB 列，需在既有部署上先执行一次迁移或依赖运行时自动补列（首次请求 ensureBookReasonColumn）；全新部署走 schema/migration。
- 内联分类/标签管理为交互重构，需在真实浏览器中人工确认无布局推挤与焦点问题（typecheck/build 已通过，未做浏览器端到端验证）。
