## 背景与需求

全盘 review 后与用户确认的 v1.3.0 功能批次（原需求总纲 §6 兜底链在本版落地；原规划「JSON 备份」经用户确认改为 CSV 全量导出形态）：

1. **手动上传封面**：豆瓣抓不到封面或用户想用自定义图时，可在编辑表单直接上传本地图片。
2. **元数据兜底源**：豆瓣抓取是单点（数据中心 IP 可能被封、版式变体会漏字段），ISBN 抓取失败时自动按兜底链补位。
3. **CSV 全量备份**：v1.2.0 列表瘦身使导出丢失简介/笔记/录入理由；导出改为全量备份语义，并与导入形成可还原闭环。

## 已确认的决策

| 决策点 | 结论 |
|-------|------|
| 备份格式 | **CSV 全量导出**（用户确认，不做 JSON）；新列追加在表头末尾保持向后兼容 |
| 兜底源范围 | NeoDB → Open Library → Google Books 三源全做（用户确认），顺序按中文数据质量与稳定性排列 |
| 兜底触发 | 仅 **ISBN 模式**走兜底链；豆瓣链接模式仍只走豆瓣（链接模式无检索关键词，无法兜底） |
| 配置成本 | 兜底源零配置、零密钥，保持 fork 即部署（实现前实测 NeoDB 匿名可用） |
| 上传入口位置 | 编辑已有书籍时的表单内（新增书籍无 id，不提供上传）；上传后仅回填封面 URL 字段，随表单保存生效 |
| 上传类型限制 | 仅 JPG/PNG/WebP/GIF 位图、≤5MB（与抓取封面一致；拒绝 SVG 防同源脚本执行） |

## 功能设计

### 1. 手动上传封面

- 端点：`POST /api/books/:id/cover`（session 鉴权，multipart 字段 `file`）。
- 存储：R2 key 为 `upload-<bookId>.<ext>`（按书稳定命名，重传覆盖），返回 `/api/covers/:key` 站内路径。
- 交互：编辑表单「封面 URL」下方出现「上传封面」按钮，上传成功把站内路径填入封面 URL 输入框，toast 提示「点击保存生效」；用户取消保存则不改动书籍字段（孤儿文件由既有存储检查/清理链路回收）。
- 清理：书籍彻底删除/清空回收站的联动清理按 `cover_url` 引用判断，上传封面自然纳入。

### 2. 元数据兜底源（`src/lib/metadata-fallback.ts`）

- 链路：豆瓣（`book-metadata.ts`，优先）→ NeoDB → Open Library → Google Books。
- NeoDB：`GET /api/catalog/search?query=<isbn>&category=book` 取首个版本 → `GET /api/book/{uuid}` 取详情（title/subtitle/author/translator/publisher/pub_year/isbn/pages/cover/rating/description），并从 `external_resources` 反查豆瓣链接回填 `douban_url`；评分同为 10 分制直接映射。
- Open Library：`/api/books?bibkeys=ISBN:<isbn>&format=json&jscmd=data`（对中文 ISBN 覆盖差，作二兜底）；评分缺省。
- Google Books：`/api/books/v1/volumes?q=isbn:`（对 Cloudflare 出口 IP 常见匿名配额 429，作末位兜底）；`averageRating` 为 5 分制 ×2 换算。
- 容错：单个源网络/解析失败仅记日志并继续下一源；全部未命中抛错由端点统一返 400。
- 缓存：复用 `book-metadata.ts` 的 KV 缓存工具，键 `meta:<source>:isbn:<isbn>`，TTL 24h，`force` 语义一致。
- 封面：兜底源的封面同样走 `storeCover` 下载入 R2（Referer 仅对豆瓣图床携带）。
- `books.source` 落实际命中来源（`douban/neodb/openlibrary/googlebooks`，均在建表 CHECK 枚举内）。

### 3. CSV 全量备份导出/导入

- 导出：`GET /api/export/books` 改用全字段查询 `listAllBooksFull()`（详情 SELECT + 分页 200/页），不再受列表瘦身 `LIST_SELECT` 影响；`BOOK_COLUMNS` 末尾新增「封面」列。
- 导入：preview/batch 映射补 `封面` 列；batch 逐条 zod 校验（长度/枚举/URL 白名单），配合 CSV ≤2MB、≤1000 行、单批 ≤50 条的上限。
- 防护：导出单元格做 CSV 公式注入转义（`= + - @` 开头加 `'` 前缀）。

## 不做的事（YAGNI）

- 不做 JSON 导出/导入（用户确认 CSV 形态）。
- 不做兜底源的手动指定/排序配置（固定链顺序）。
- 不为新增书籍（未入库）提供封面上传。
- 不改动豆瓣抓取解析逻辑与「非空不覆盖」回填策略。
