# 网站书本图标实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Bookshelf 网站增加与现有品牌一致的浏览器标签页书本图标。

**Architecture:** 仅修改前端 HTML 入口 `src/web/index.html`，在 `<head>` 中加入使用 data URL 内嵌的 SVG favicon。图标采用橙色渐变背景和白色打开书本图案，不新增依赖、不修改后端或部署配置。

**Tech Stack:** HTML、内联 SVG data URL、Vite、TypeScript 项目构建流程。
