## 设计目标

让网站在现代浏览器标签页中显示与“我的书架”品牌一致的书本图标，同时保持实现范围最小，不引入额外依赖或后端改动。

## 方案

- 在 `src/web/index.html` 的 `<head>` 中增加 favicon 声明。
- 使用内联 SVG 的 data URL，避免新增二进制资源文件。
- 图标背景使用页面现有的橙色渐变视觉。
- 图标主体使用简洁的白色打开书本图案，保证小尺寸下仍具辨识度。
- 不修改页面内左上角 Logo，不修改 API、数据库、Worker 或部署配置。

## 验收标准

- 构建后的 HTML 包含 favicon 声明。
- 浏览器标签页能够请求并显示该图标。
- TypeScript 类型检查通过。
- 构建代码阶段通过，且无新增依赖和敏感信息。
