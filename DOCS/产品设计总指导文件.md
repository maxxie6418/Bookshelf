## 1. 信息架构（IA）

- **书架主页（主视图）**：顶栏 + 侧栏 + 书籍列表（表格/网格切换）。
- **登录页**：首次/会话失效时全屏。
- **详情抽屉**：从列表点开，右滑。
- **添加/编辑表单（弹窗）**：新增或编辑一本书。
- **设置/导入导出面板**：导入导出入口、AI 配置说明（api_key 走 secret，无 UI）、暗色切换、**修改口令**。
- **回收站**：侧栏入口，列出软删书目，支持"恢复"与"彻底删除（二次确认）"。
- 原型 `bookshelf-prototype.html` 已演示主视图、详情抽屉、添加弹窗，本文件据此补齐组件职责与缺口（编辑表单、登录页、导入导出面板）。

## 2. 设计 Token（取自原型）

| Token | 值 | 用途 |
|-------|----|------|
| shelf-50..900 | `#faf9f7` … `#1a1816` | 米色中性色板（背景/文字/边框） |
| 强调色 | `amber-500`(`#f59e0b`) / `orange-600` | 主按钮、激活态（暗色下用 amber） |
| 字体 | `Inter`(sans) / `Noto Serif SC`(serif, 标题) | |
| 圆角 | `rounded-xl` / `rounded-2xl` | 卡片/弹窗 |
| 阴影 | `shadow-2xl` / `shadow-lg` | 抽屉/弹窗/FAB |
| 暗色 | `class="dark"` 挂 `<html>` | 全局切换，配 `dark:bg-shelf-900` 等 |
| 缺图兜底 | `cover-pattern-1..12` 渐变 | 无封面时按 id 取渐变 |
| 封面代理 | Cloudflare Image Resizing | `cover_url` 为远程地址，经 Image Resizing 按需缩放；不落 R2 |

## 4. 组件清单

### App / AppShell
- 职责：登录态判定、布局骨架、路由占位、全局 Toast 容器。
- 状态：`authed`、`theme`、`currentView`('table'|'grid')、`filters`。
- 交互：未登录渲染 `LoginPage`；登录后渲染 `AppShell`。

### NavBar
- 职责：搜索、视图切换、主题切换、新增入口。
- props：无（读全局状态）。
- 交互：搜索输入防抖 300ms 触发列表过滤；视图切换写 `currentView`；主题切换持久化到 localStorage 并切 `<html>.dark`。

### Sidebar
- 职责：状态 / 分类 / 标签筛选。
- 状态：`activeStatus`、`activeCategory`、`activeTags[]`。
- 交互：点击即更新全局 filters；移动端默认收起，由菜单按钮开合（原型 `menuToggle` / `sidebarOverlay`）。
- 回收站入口（`TrashEntry`）：展示待清理数量角标，点击切到回收站视图。
- 缺口：原型已有，需补"全部分类/标签"清空态。

### SearchBar
- 职责：书名/作者/ISBN 关键词。
- 交互：防抖 → 更新 `filters.q`。

### ViewToggle
- 职责：表格/网格切换；受控于 `currentView`。

### ThemeToggle
- 职责：暗色切换；读/写 localStorage。

### BookList（容器）
- 职责：按 filters 调 `GET /api/books`，渲染 `BookTable` 或 `BookGrid`；负责分页/全量、空态、加载态。
- 状态：`items`、`total`、`loading`。

### BookTable
- 职责：Notion 式行：封面缩略、书名、作者、状态、分类、标签、更新时间。
- 交互：行点击 → `DetailDrawer`；状态可用下拉快速切换（PATCH）。

### BookGrid / BookCard
- 职责：卡片：封面（或渐变兜底）、书名、作者、状态角标。
- 交互：hover 上浮（`translateY(-4px)`）；点击 → `DetailDrawer`。

### DetailDrawer（BookDetail）
- 职责：右滑抽屉展示完整字段；含"编辑""关闭"按钮（原型已有"编辑"但无表单）。
- 缺口：**编辑按钮需打开 `BookForm`**（原型未实现）。

### BookForm（添加/编辑共用）
- 职责：字段录入：书名*、副标题、作者、译者、出版社、出版年、页数、ISBN、简介、封面（URL 或留空）、状态(4 态)、分类(下拉选 id)、标签(回车添加 name 数组)、豆瓣链接(触发抓取预填)。
- 交互：填豆瓣链接/ISBN → `POST /api/books/metadata/fetch` → 预填；提交 `POST`(新增) 或 `PATCH`(编辑)。状态切到"在读/读完"时由服务端写 `started_at`/`finished_at`。
- 缺口：原型仅有"添加"弹窗，需补"编辑"复用同一表单。

### LoginPage
- 职责：口令登录；首登强改口令（`must_change_password`）。
- 缺口：原型**完全缺失**，需新建。失败 5 次显示封锁倒计时；首登（`must_change_password=1`）强制改口令。

### ImportExportPanel
- 职责：导出（JSON/CSV 下载）、导入（上传/粘贴 → `POST /api/import`，展示 `{imported,updated,skipped,errors}`）、**修改口令**、AI 配置说明（api_key 走 `wrangler secret`，本面板不收集密钥）。
- 缺口：原型缺失，需新建。

### TrashPanel（回收站）
- 职责：列出软删书目（`GET /api/books/trash`）；每行"恢复"（`POST /api/books/:id/restore`）与"彻底删除"。
- 交互："彻底删除"必须先弹**二次确认**对话框，确认后 `DELETE /api/books/trash/:id`（物理删，不可逆）；支持"清空回收站"同样二次确认。角标显示待清理数量。

### FAB / EmptyState / Toast
- 职责：移动端新增悬浮按钮；列表空态插画/文案；操作反馈。

## 5. 关键交互流程

1. **豆瓣录入**：添加弹窗填链接/ISBN → 抓取预填 → 用户核对/补 → 提交。
2. **筛选浏览**：侧栏选状态/分类/标签 + 搜索 → 列表实时过滤（前端防抖 + 后端参数化）。
3. **AI 查询**：主页查询框输入自然语言 → `POST /api/query` → 结果以列表呈现（复用 BookList）。
4. **导入导出**：设置面板导出当前/全量；导入文件 → upsert → 展示统计与错误。
5. **删除→回收站**：列表删除 → 软删进回收站；回收站"恢复"回库，或"彻底删除"二次确认后物理删。

## 6. 响应式规则

- 断点：`lg`(1024px) 以上常驻侧栏；以下抽屉式（原型 `sidebar.transform`）。
- 网格：`grid-cols-2`(手机) → `sm:3` → `md:4` → `xl:5` → `2xl:6`。
- 移动端：新增用 FAB；详情用全宽抽屉；表单弹窗全宽。
- 顶栏搜索在移动端折叠（`hidden md:flex` 主体 + 移动搜索行）。

## 7. 空态 / 加载 / 反馈

- 列表空：提示"还没有书，点 + 添加第一本"。
- 加载：骨架屏或 spinner；抓取预填时按钮 loading。
- 反馈：Toast 成功/失败；导入结果以列表展示错误行。
